# Contributing

This project is developed by two students using Git and GitHub.

## Collaboration workflow
1. Student 1 initializes the repository and pushes the initial project to GitHub.
2. Student 2 clones the repository.
3. Each student works on their own feature branch:
   - `feature-member1`
   - `feature-member2`
4. Each student makes at least four meaningful commits.
5. Each student opens a pull request and reviews the partner's pull request.
6. Both branches are merged into `main`.
7. Both students participate in creating and resolving a merge conflict.

## Suggested responsibility split
- Student 1: book management and main menu.
- Student 2: member management and issue/return transactions.
